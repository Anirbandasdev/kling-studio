The shape of it

Two buttons, in order

Every clip is made twice: first as a still picture, then as five seconds of video built from that picture. You look at the stills in between, which is the whole point — a bad frame is cheap to redo, a bad video is not.

Master prompt Claude writes it. One block of text with an image prompt and a motion prompt for every clip. In the chat
Frames Nano Banana 2 draws one still per clip. You review them and redraw anything that came out wrong. Step 1 · 12 credits each
Videos Kling 3.0 animates each approved frame and the mp4 files land in your output folder. Step 2 · 90 credits each
Nothing is ever sent without you pressing a button. Both generate steps show the exact credit cost first and wait for you to confirm. Checking on work already paid for is always free.
Step one

Install it

Both installers live on the same page. Download the one for your computer, then follow your column below.

WindowsKlingStudio-Setup-3.0.4.exe · 14 MB
macOSKlingStudio-3.0.4-mac.dmg · 14 MB

Windows

10 or 11

  1. Run the Setup file

    Double-click KlingStudio-Setup-3.0.4.exe from your Downloads folder.

  2. Get past the blue box

    Windows stops apps it hasn't seen before. Click More info, then Run anyway. It is not a virus warning — it means the app has no paid signing certificate.

  3. Click through the installer

    It reads you a short page of notes, then installs into your own user folder. No administrator password, no IT ticket.

  4. Open it from the Start menu

    Search for Kling Studio. The same blue box may appear once more on first launch — same answer.

macOS

Apple or Intel

  1. Open the .dmg

    Double-click KlingStudio-3.0.4-mac.dmg. A window opens with the app and an Applications shortcut.

  2. Drag it to Applications

    Drop Kling Studio onto the Applications folder in that window, then eject the disk image.

  3. Right-click to open, the first time only

    In Applications, right-click Kling Studio → Open, then Open again in the box. Double-clicking it the normal way will just be refused until you've done this once.

  4. Still blocked?

    System Settings → Privacy & Security, scroll down, and click Open Anyway next to the Kling Studio message.

Step two

Connect your kie.ai key

The app doesn't have an account of its own — it runs on yours. That means the credits are yours, the history is yours, and nobody shares a login.

  1. Sign in at kie.ai

    Go to kie.ai, sign in, and open the API key page from your dashboard.

  2. Copy the key

    It's a long string of letters and numbers. Copy the whole thing.

  3. Paste it into Settings

    In Kling Studio, click Settings in the bottom-left corner, paste into kie.ai API key, and press Save. On a fresh install the app asks for it straight away.

  4. Put credits on the account

    Top up on kie.ai. If the balance runs out mid-batch the app stops immediately, keeps everything already paid for, and says so on the batch page.

Your key stays on your own machine. It is not sent anywhere except kie.ai, and it is not in the app's code or on GitHub.
Step three

Get the master prompt from Claude

You never type the prompt block by hand. When the script is final, run the skill in your Claude chat and it writes the whole thing.

Type /kling-studio in the chat. It reads the shots you've been working on, asks you for a batch name, and prints one block. Select it, copy it, done — no files, no setup, nothing to upload.

LineWhat it does
batch:Names the batch, its folder, and every clip inside it (c150_clip01 and so on).
image:What the still picture shows. This is what Nano Banana 2 draws.
motion:What moves. This is what Kling 3.0 animates, using the frame above it.
ref: frame 1Keeps a face or product identical across clips — frame 1 is drawn first, then reused as the reference.
ref: neededThe app will stop and ask you for a picture for that clip before it draws anything.
settings:Optional. Only appears when something differs from 9:16 · 5s · Pro · sound off · 2K.

Step six

Make the videos

Same button, second step. Only clips that already have a frame can be animated, and the credits are confirmed again separately.

When everything is finished the button stops being a button — it turns into a green All done marker, and each card plays its clip when you hover it. Open folder shows you the files:

c150/ frames/ c150_clip01.png, c150_clip02.png … videos/ c150_clip01.mp4, c150_clip02.mp4 … refs/ reference pictures you attached job.json the prompts and settings for this batch state.json what is done, what failed activity.log everything shown under Activity
Six clips take a few minutes. You can close the window while it works — the batch carries on and the files still arrive.

Keeping current

Updates arrive on their own

The app checks for a new version a few seconds after it starts, and every six hours after that. You'll see a green chip above the sidebar buttons.

On Windows

One click

Press Install and restart. The app downloads the new build, checks it against a published checksum, closes, swaps itself over and reopens. No admin rights. SmartScreen may ask once more after the swap — More info → Run anyway.

On macOS

One drag

Press Release page, download the new .dmg, and drag the app into Applications over the old one. macOS won't let an app replace itself, so this part stays manual.

When it goes wrong

Every failure prints its reason on the clip card. Here is what each one means and what to do about it.

What it saysWhat happenedWhat to do
kie.ai failed itThe model rejected the prompt — usually content moderation, occasionally a wording it can't parse.Edit the prompt, then press Frame or Video on that card. costs that one clip
Timed out / Check failed / Download failedThe work may well be finished at kie.ai — the app just lost track of it.The big button offers a free re-check. Free
Couldn't sendThe request never reached kie.ai, so nothing was charged.The big button sends it again.
Needs a referenceThe prompt said ref: needed and no picture has been supplied yet.Add the picture in the popup, or reuse another clip's frame. Free
Reference missingThis clip copies from a frame that never arrived.Fix that frame first, then this one.
The run stopped earlyA rejected API key or an empty balance. Everything already paid for is kept.Check the key in Settings, or top up on kie.ai, then press the big button again.
Still stuck? Open the batch folder and send activity.log and anything inside responses/ — that's the raw answer kie.ai gave, and it says exactly what went wrong.
